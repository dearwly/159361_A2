# 🏰 DUNGEON SLAYER

### A Unity Action Game Project

---

## 📖 Game Overview
**DUNGEON SLAYER** is a fast-paced action adventure game developed in Unity.  
Players take on the role of a dungeon warrior who must defeat monsters, manage stamina and health, and survive through multiple levels using skills and strategy.

The game features immersive background music, responsive controls, and dynamic sound effects that bring the dark dungeon atmosphere to life.

---

## 🎮 How to Start the Game
1. Open the Unity project.  
2. In the **Assets** folder, locate and open the scene named **MainMenu**.  
3. Click the **New Start** button in Unity to start the game.

## ⚔️ Gameplay Instructions

### 🎯 Basic Controls
| Action | Key / Mouse |
|:-------|:-------------|
| Move | **W / A / S / D** |
| Attack | **Left Mouse Button** |
| Pause Menu | **Esc** |
| Use Skill 1 | Area Attack | **E** |
| Use Skill 2 | Attack Boost | **Q** |
| Use Skill 3 | Heal (Potion) | **R** |

---

### 💡 Game Mechanics
- **Health Bar (Red):** Displays the player's current HP.  
- **Stamina Bar (Yellow):** Decreases when performing actions like attacking or sprinting.  
- **E Skill (Ultimate Attack):** A powerful area attack that instantly defeats nearby enemies.  
- **Q Skill (Attack Boost):** Temporarily increases attack power by **1.5x**.  
- **R Skill (Healing Potion):** Restores health; can be used up to **five times**.  
- **Pause Menu:** Press **Esc** to pause the game, adjust volume, or return to the main menu.  
- **Level Progression:** Reaching the end of a level automatically loads the next one.  

---

## 🔊 Audio Features
- Background music enhances the dungeon atmosphere.  
- Attack and enemy sound effects add immersion.  
- Female ghost enemies emit distinct screams.  
- Volume can be adjusted in the **设置** menu.
